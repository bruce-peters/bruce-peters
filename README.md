### Projects

**[Word Wiz AI](https://github.com/bruce-peters/word-wiz-ai)** &nbsp;`FastAPI` `React` `Wav2Vec2` `AWS EC2/RDS`
&nbsp; Adaptive reading platform for early learners. Five integrated ML models handle speech-to-text, phoneme conversion, grapheme alignment, TTS, and LLM feedback generation. Detects specific mispronounced phonemes in real time, distinguishing sounds like "HOSE" from "HOUSE." Response latency reduced from 15s to 2s through streaming, model quantization, and selective API caching. 210 users, 11K+ visitors. **2nd Place, Congressional App Challenge CA-15.**

**Off-Task Detection Research** &nbsp;`Python` `Swift` `PyTorch` `WhisperX` `YOLO`
&nbsp; Ongoing research at BU's H2X Lab, started during the BU RISE program and continuing remotely. The goal is to detect and classify off-task behavior in one-on-one K-2 reading sessions from video alone. I built a behavioral taxonomy for what "off-task" actually means in this setting, then a multimodal pipeline around it: diarized transcription with WhisperX, pose estimation with YOLO, gaze target estimation, and VLM inference over the resulting features.
&nbsp; [word-level-gaze-target-detection](https://github.com/bruce-peters/word-level-gaze-target-detection) estimates which word on screen a reader is fixating on, where the hard part is the line changes and back-jumps that break naive gaze mapping. [dogma-annotation-helper](https://github.com/bruce-peters/dogma-annotation-helper) is the tooling built to label the DOGMA dataset against that taxonomy.

**[Iron Panthers 2026](https://github.com/Iron-Panthers/OFFSEASON-2026)** &nbsp;`Java` `WPILib`
&nbsp; Current robot code for Team 5026. I lead programming and maintain the simulation platform that lets the team test subsystems without hardware, which roughly tripled how fast we can iterate. [FRC-2026](https://github.com/Iron-Panthers/FRC-2026) is the competition season code that took us back to the World Championship.

**[Iron Panthers Scouting App](https://github.com/Iron-Panthers/2025-scout)** &nbsp;`React` `Vite` `Tailwind`
&nbsp; Competitor analysis tool I built from scratch for Team 5026. Aggregated live match data across the 2025 FRC season to drive alliance selection and in-game strategy. Deployed and used at the World Championship in Houston.

**[FRC-2025-GPT](https://github.com/bruce-peters/FRC-2025-GPT)** &nbsp;`Java` `Python` `MCP`
&nbsp; Experimental AI layer on top of our competition robot code. Integrates an MCP client alongside WPILib Java to give the robot autonomous decision-making capabilities beyond standard command-based state machines.

**[Notes Review App](https://github.com/bruce-peters/notes-review-app)** &nbsp;`Vite` `Tailwind` `Jest`
&nbsp; Drops your raw notes into an LLM, extracts key facts, and turns them into a typing-test-style drill. Built for AP World History. [Live here.](https://bruce-peters.github.io/notes-review-app/)
