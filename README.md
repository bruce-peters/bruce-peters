### Projects

**[Word Wiz AI](https://github.com/bruce-peters/word-wiz-ai)** &nbsp;`FastAPI` `React` `Wav2Vec2` `AWS EC2/RDS`
&nbsp; Adaptive reading platform for early learners. Five integrated ML models handle speech-to-text, phoneme conversion, grapheme alignment, TTS, and LLM feedback generation. Detects specific mispronounced phonemes in real time, distinguishing sounds like "HOSE" from "HOUSE." Response latency reduced from 15s to 3s through streaming, model quantization, and selective API caching. 411 commits, 400+ users. **2nd Place, Congressional App Challenge CA-15.**

**[Iron Panthers Scouting App](https://github.com/Iron-Panthers/2025-scout)** &nbsp;`React` `Vite` `Tailwind`
&nbsp; Competitor analysis tool I built from scratch for Team 5026. Aggregated live match data across the 2025 FRC season to drive alliance selection and in-game strategy. Deployed and used at the World Championship in Houston.

**[FRC-2025-GPT](https://github.com/bruce-peters/FRC-2025-GPT)** &nbsp;`Java` `Python` `MCP`
&nbsp; Experimental AI layer on top of our competition robot code. Integrates an MCP client alongside WPILib Java to give the robot autonomous decision-making capabilities beyond standard command-based state machines.

**[Notes Review App](https://github.com/bruce-peters/notes-review-app)** &nbsp;`Vite` `Tailwind` `Jest`
&nbsp; Drops your raw notes into an LLM, extracts key facts, and turns them into a typing-test-style drill. Built for AP World History. [Live here.](https://bruce-peters.github.io/notes-review-app/)

**[Phoneme Assistant](https://github.com/bruce-peters/phoneme-assistant)** &nbsp;`Python` `Jupyter` `ElevenLabs`
&nbsp; The ML research prototype that became Word Wiz AI. Forced-alignment pipeline for phoneme extraction and speech-problem classification before the architecture moved to Wav2Vec2.
